# 제품 방향 및 후속 사용 흐름

Space Inspector는 드라이브 공간 확보를 돕는 전문 파일 검색·분석·관리 프로그램이다. 파일 탐색기 연결은 원본 위치를 확인하기 위한 선택 기능이며, 검색·인덱스·중복 분석은 Windows 탐색기와 독립적으로 수행한다. 탐색기 대체나 단순 파일 목록 뷰어로 한정하지 않는다.

## 단계별 자원 사용

최초 대규모 인덱싱과 관리 분석은 상당한 CPU/메모리/디스크 I/O를 사용할 수 있다. 현재는 작업 스레드에서 탐색/해시를 실행하고, 메타데이터 배치 쓰기, DB에 후보 목록 저장, 페이지 조회, 순차 해시 읽기, 취소를 사용한다. 모든 파일을 메모리에 올리거나 무제한 병렬 읽기하지 않는다. 이는 리소스 상한을 보장하는 완성된 백그라운드 서비스가 아니다.

기능 구현 후에는 사용자가 자신의 업무를 계속할 수 있는 백그라운드 모드를 제공한다. 후속 구현 항목:

- CPU 및 디스크 I/O 사용량을 측정하는 저부하/균형/집중 모드
- 사용자 활동·유휴 상태·전원 상태에 따른 조절과 일시 중지/재개
- 장치별 작업 큐, 동시 읽기 제한, 읽기 속도 제한
- 앱 종료/재시작 후 이어 하기, 연결 해제된 외장 드라이브 작업 대기
- 변경 감지와 누락 확인을 결합한 증분 갱신 (이벤트 유실 및 감시 버퍼 초과 처리)
- 임의의 사용자 파일 변경, 권한 변경, 온라인 전용 다운로드 없이 동작
- 검색 반응성, 취소 지연, 작업 중 일반 업무 반응성의 장시간 실측

## 합의된 후속 검색 흐름

현재 Phase 개발 순서를 유지하고 아래 사용 흐름은 기능 기반이 안정화된 뒤 적용한다.

1. 드라이브 검색 / 폴더 검색 모드를 나누고 서로 배타적으로 선택한다. 각 모드에서는 여러 대상을 선택할 수 있다.
2. 범위와 조건을 지정해 바로 검색한다. 기존 인덱스가 있으면 먼저 표시하고 최초/추가 범위는 자동으로 탐색한다.
3. 탐색 중 결과가 추가되는 상태를 명확히 표시한다. 미완료 탐색을 검색 완료로 표시하지 않는다.
4. 이후 삭제·이동·수정은 증분 갱신하고 누락 확인을 위한 재확인을 병행한다.
5. 수동 인덱스 새로고침은 보조 작업으로 유지한다.

## 외장 장치 기반 (선행 구현)

드라이브 문자와 파일의 정체성을 분리한다. 현재 Windows 볼륨 GUID + 볼륨 일련번호 + 파일 시스템 이름, 볼륨 내 상대 경로를 기록한다. 같은 볼륨이 다른 문자에서 재검사되면 기존 FileId와 경로를 연결한다. 같은 문자를 다른 볼륨이 쓰면 기존 행을 보존하고 별도 행으로 저장한다.

이 식별자는 이 PC의 Windows 볼륨 식별 정보이며 물리 USB 장치의 불변 하드웨어 ID를 의미하지 않는다. 포맷, 복제, 다른 OS/PC, 식별 실패 등은 재확인이 필요하다. 식별할 수 없으면 자동으로 같은 장치라고 합치지 않는다. 기존 식별 없는 데이터는 실제 재검사에서 확인한 항목부터 연결한다. 연결 상태 및 경로 실시간 재매핑은 추후 백그라운드 갱신과 통합한다.
