# Space Inspector 재개발 계획 v2

기준일: 2026-11-18. 사용자와 합의한 변경 요구를 우선한다. 기존 PRD와 Phase 1~4는 참고 자료이며, 충돌할 경우 이 계획을 따른다. 이 문서는 구현 완료 보고가 아니다.

## 목적과 범위

사용자가 지정한 파일을 검색·비교·관리하여 드라이브 공간 확보를 돕는 독립적인 Windows 프로그램이다. 탐색기 연결은 선택적인 위치 확인 기능이다. 이번 개발은 대상 설정 → 탐색 → 동일 내용 중복 비교 → 부분/완료 결과 확인에 집중한다. 원본 파일을 변경하지 않는다.

자동 삭제·이동, 유사 이미지/영상 판별, 미디어 메타데이터 확장, OneDrive 전용 기능, 자동 변경 감시, 상시 백그라운드 서비스는 보류한다. 이후 일반 업무와 공존하는 저부하 작업 모드를 개발할 수 있도록 작업 실행과 화면을 분리한다.

## 사용자 흐름

1. 드라이브 또는 폴더 모드를 선택한다. 한 작업에 두 모드를 섞지 않으며 각 모드에서 여러 위치를 선택할 수 있다.
2. 하위 폴더 포함 여부를 정한다. 미포함이면 선택 위치 바로 아래 파일만 대상이다.
3. 이미지(JPG/JPEG/GIF/PNG 등), 동영상(AVI/MP4/MPG/WMV/FLA 등), 오디오(WAV/M4A/MP3/WMA 등), 캐시/임시 파일을 선택한다. 분류는 편집 가능한 확장자 프리셋이며 콘텐츠 형식 검증이나 미디어 재생 지원을 뜻하지 않는다. 캐시/임시는 확장자만으로 단정하지 않고 경로와 보호 규칙도 사용한다.
4. 실행하면 해당 범위를 탐색하고 비교한다. 별도의 전체 드라이브 인덱싱을 선행 조건으로 요구하지 않는다. 기존 인덱스는 참고 캐시이며 현재 작업 범위를 확대하지 않는다.
5. 진행 상태, 확인된 결과, 후보, 미처리, 응답 대기를 구분해 확인한다. 결과에서 경로 복사와 위치 열기를 제공한다.

페이징·최대절전 등 시스템 사용 파일은 용량 확인과 중복 검사를 분리한다. 일반 중복 비교 및 정리 대상에서 제외하고 이유를 표시한다. 사용자 선택이 온라인 전용 파일 다운로드, 링크 추적, 시스템 보호 해제를 자동으로 허용하지 않는다.

## 작업 계약

- 실행 시 대상 모드, 정규화된 위치, 볼륨 식별, 재귀 여부, 확장자/분류, 보호 및 권한 처리 정책을 변경 불가능한 작업 설정으로 저장한다. 실행 중 화면 설정을 바꾸면 다음 작업에 적용한다.
- 인덱싱·검색·중복 후보 생성·결과 조회는 모두 같은 작업 ID와 대상 집합을 사용한다. 전체 인덱스의 다른 파일이 비교나 결과에 섞여서는 안 된다.
- 범위가 겹쳐도 파일을 중복 처리하지 않는다. 재귀 미포함 모드에서는 부모 폴더 선택이 별도로 선택한 자식 폴더를 제거하지 않는다.
- 범위 밖 기록을 Missing으로 변경하지 않는다. 확장자 조건을 변경해도 기존 다른 유형의 기록을 삭제하지 않는다.
- 드라이브 문자만으로 동일 장치로 판단하지 않는다. 장치 분리·교체는 해당 항목만 보류하고 다른 대상은 계속 처리한다.

## 권한과 응답 대기

권한 부족이나 미설정 상황이 생기면 해당 파일/폴더만 응답 대기 큐에 저장한다. 나머지 작업은 계속한다. 작업을 막는 질문 창을 반복해서 열지 않고 알림과 대기 목록을 제공한다. 이유, 경로, 선택 가능한 조치, 재시도 결과를 기록하고 동일 원인의 알림을 묶는다.

사용자는 건너뛰기 또는 허용된 재시도를 선택한다. 관리자 권한이 필요한 경우 명시적으로 요청할 수 있지만 Windows의 UAC 승인을 우회하거나 자동으로 ACL을 변경하지 않는다. 권한 상승 작업은 주 작업을 중단하지 않는 별도 실행 경로로 설계한다. 관리자 권한으로도 실패하면 이유와 함께 대기/건너뜀으로 남긴다. 무한 재시도하지 않는다.

접근 가능한 작업을 모두 처리했으나 응답이 남으면 '처리 가능한 항목 완료 · 응답 대기 N건'으로 표시한다. 전체 완료로 표시하지 않는다. 답변이 오면 같은 작업에 재시도 항목을 추가한다. 취소한 작업은 답변만으로 자동 재개하지 않는다.

## 진행·취소·결과

초기 실행에는 인덱스 준비 안내와 애니메이션을 표시한다. DB 열기, 백업, 구조 변경, 기록 불러오기 단계를 구분하며, 작업량을 모르면 임의의 퍼센트나 남은 시간을 표시하지 않는다. 초기화는 파일 전체 탐색과 구분한다.

탐색/후보 추리기/부분 읽기/전체 비교/검증 단계를 표시한다. 경과 시간, 발견·처리 수, 읽은 바이트, 오류·제외·응답 대기 수를 제공한다. 전체량이 확정된 단계만 진행률을 제공한다.

취소 요청 후 신규 작업 배정을 멈추고 진행 중 읽기에 취소를 전달한다. 이미 저장한 결과를 보존한다. 전체 해시가 같고 필요한 재검증을 완료한 파일끼리만 '확인된 중복'으로 표시한다. 부분 해시·크기만 확인된 파일은 후보로, 나머지는 미처리/미검증으로 남긴다. 취소 시 오래 걸리는 전체 재검증을 새로 수행하지 않는다. 이를 위해 검증 완료 여부를 작업별로 점진적으로 저장한다.

취소 결과에는 '중단 · 일부 결과'를 표시한다. 확인된 그룹도 미처리 영역에 추가 중복본이 있을 수 있다. 결과는 검사 시점 기준이다. 논리적 중복 용량은 실제 확보 가능 용량과 구분하고 하드링크를 중복 계산하지 않는다. 새 작업이 과거 작업 결과를 지우지 않도록 작업별 결과를 저장한다.

## 구현 순서와 완료 기준

### R1 — 범위가 일관된 최소 실행 흐름

작업 설정과 작업별 대상 저장을 도입하고 드라이브/폴더 배타 선택, 재귀 여부, 파일 종류를 UI부터 탐색·분석·결과까지 연결한다. 초기화 상태를 표시한다. 작은 합성 폴더에서 범위 밖 동일 파일이 결과에 들어오지 않고 하위 폴더 포함 여부가 정확해야 완료다.

### R2 — 취소와 부분 결과

작업별 진행·검증 상태와 결과를 점진 저장한다. 크기/부분/전체 해시 각 단계에서 취소하고 재실행해도 완료 결과가 보존되고 불완전 파일이 확정 중복으로 표시되지 않아야 한다. 취소 지연은 측정하여 보고하고 블로킹 장치 I/O 한계를 숨기지 않는다.

### R3 — 질문 중에도 계속되는 실행

응답 대기 큐와 비차단 알림, 건너뛰기/재시도, 승인 기반 권한 상승 경로를 연결한다. 한 폴더가 권한 대기인 동안 다른 폴더 분석이 끝나고, 답변 후 해당 폴더만 재처리되어야 한다. 무응답·거절·장치 분리·취소 후 답변도 검증한다.

### R4 — 통합 검증과 배포

초기 DB/기존 DB 전환, 앱 종료와 중단 상태 복원, 실제 외장 드라이브, 대규모 목록, UI 반응성을 검증한다. 작업 중 사용자 업무와의 자원 경쟁을 측정하고 현재 제한을 기록한다. 일시 정지·앱 재시작 후 이어 하기는 구현/검증 전 지원한다고 표시하지 않는다. 새 실행 파일은 검증된 새 흐름과 알려진 제한을 함께 안내한다.

현재 상태: R1~R3의 새 실행 흐름과 R4 자동 통합 검증/패키징을 구현했다. 기존 Phase 4 코드는 참고 구현으로 보존하고 새 앱 진입점을 사용한다. 실제 UAC 및 물리 장치·대규모 성능 검증은 남아 있으며, 상세 동작과 검증 한계는 [v2 배포 안내](V2_RELEASE.md)를 따른다. 파일 단위 재시도 시 같은 범위의 부모 폴더를 다시 확인할 수 있고, 비교는 현재 작업 내에서 다시 수행한다.

## 후속 개발 합의 — 미디어 정리 화면 (2026-11-20)

우선순위는 중복 정리를 통한 공간 확보, 흩어진 미디어 분류 순서다. 이미지 → 동영상 → 오디오 순으로 미리보기를 확장한다. 목록/썸네일 전환, 크기 조절, 선택 미리보기 및 나란히 비교를 제공한다. 결과 탭 이동을 없애고 작업 전체 결과에 필터를 적용하며 조건을 이름으로 저장한다. 폴더별 그룹핑은 보류한다.

로컬 v2.4 미리보기에는 통합 필터, 저장 조건, 이미지 썸네일/비교와 기존 보관·휴지통 보호를 연결했다. 다음 단계는 동영상 대표 프레임과 오디오 5초 프리뷰다. 폴더 이동 및 이름 변경은 이후 단계로 두고, 실행 전 대상 확인과 변경 후 인덱스 일관성을 함께 구현한다. 자세한 실행 및 검증 범위는 V2_RELEASE.md를 따른다.

로컬 v2.5에서는 동영상 초반/중간/후반 대표 장면과 명시적 오디오 5초 프리뷰를 추가했다. Windows 기본 코덱의 지원 범위를 따르며, 소스 파일 변환이나 추가 코덱 설치는 수행하지 않는다. 합성 AVI/WAV의 실제 디코더 동작과 단위/UI 18개 검증을 마쳤다. 다음 단계는 폴더 이동 및 이름 변경이다.

2026-11-21 로컬 v2.6: 선택 파일 한 개의 같은 볼륨 내 이동·이름 변경, 실행 전 확인, 덮어쓰기 거부, 작업 인덱스/결과/보관 경로 갱신 및 중단 후 기록 복구를 구현했다. 범위 밖 이동은 명시적으로 비교 대상에서 제외하며 기존 작업 범위를 확장하지 않는다. 검증은 단위/UI 18개와 통합 70개 통과, 하드링크/Junction 2개 건너뜀이다. 다른 볼륨으로의 검증된 복사 후 원본 제거, 일괄 이동/이름 변경, 자동 되돌리기는 후속 범위다.


2026-11-21 로컬 v2.7: 현재 페이지 다중 선택, 일괄 접두어/연속 번호 이름 변경, 일괄 이동, 변경 전후 경로 검토와 전체 사전 검사, 중단 시 완료/실패/미처리 결과를 구현했다. 다른 볼륨 이동은 복사본 SHA-256 검증과 최종 게시 후 원본 제거를 사용하며 새 볼륨/물리 파일 ID와 보관 기록을 갱신한다. 중단 복구는 파일 상태를 확인해 기록을 정리하며 원본 삭제를 자동 재실행하지 않는다. 실제 NTFS C:→E: 합성 파일 이동을 포함해 99개 통과, 기존 링크 관련 2개 건너뜀. 상세 사용법·제약·재현 방법은 V2_RELEASE.md의 v2.7 항목을 따른다.

합의한 주요 미디어 정리 흐름(통합 검색/저장 조건 → 이미지·동영상·오디오 미리보기 → 단일/일괄 이동·이름 변경)을 로컬 미리보기에서 구현했다. 후속 범위는 자동 되돌리기, 추가 스트림/EFS 및 다른 파일 시스템 지원, 대규모·장시간 성능과 실제 외장 장치 분리 검증이다. 폴더별 그룹핑은 계속 보류한다. 원격 반영과 정식 배포는 별도 단계다.
